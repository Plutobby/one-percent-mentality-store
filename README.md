# 1percent Mentality Store

A responsive static storefront draft built with HTML, CSS, and JavaScript.

## Open in VS Code

1. Extract the ZIP archive.
2. In VS Code, choose **File → Open Folder…** and select `one-percent-mentality-store`.
3. Open `index.html` to continue editing.
4. To preview, run a local static server from this folder, or use the VS Code Live Server extension.

The product links currently point to the two Selar pages provided.

## Adding products

The Books section uses a responsive grid. To add another book, duplicate a `.product-card` inside `.product-grid` in `index.html`, then update its cover, audience, included materials, price, and checkout link. The grid automatically adds columns or rows based on the available space.

The Merch section is currently a coming-soon placeholder. When merchandise is ready, replace its teaser panel with product cards that include product photos, sizes or colors, pricing, shipping details, and checkout links.
